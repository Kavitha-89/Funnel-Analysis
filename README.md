# User Funnel Analysis

## Objective
Analyze user progression through a conversion funnel and identify where users drop off.

## Dataset
- funnel_events_sample.csv

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Analysis Performed
- Data exploration
- Duplicate removal
- Data quality checks
- Funnel aggregation
- Conversion rate calculation
- Drop-off analysis
- Funnel visualization
- Time-to-convert analysis
- Segment comparison

## Key Findings
- Total Visitors: 200
- Purchases: 44
- Overall Conversion: 22%
- Largest Drop-off: signup_started → details_filled (54 users)

## Recommendation
Simplify the registration form by reducing required fields, adding auto-fill, and providing a progress indicator to improve conversions.
